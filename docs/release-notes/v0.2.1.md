# Bootwitch v0.2.1

## Release summary

Bootwitch v0.2.1 is a documentation and release-platform polish release that keeps the existing stable runtime behavior while improving how the scaffold describes and distributes itself.

- Added clearer adaptive docs mount flow for language-aware documentation providers.
- Added release automation for Homebrew formula updates tied to GitHub releases.
- Split generated documentation into two consistent layers: component-facing README references and function-level technical readthrough content.
- Added safer, faster readme refresh behavior with clearer build recovery semantics.
- Updated top-level docs so the release state is explicit and portfolio-ready.
- Post-release follow-up: fixed adaptive mount metadata drift in the shell template and added lint-safe handling for dynamic documentation-module sourcing in README initialization/build wrappers.

## Post-release maintenance

- Bootwitch now installs through the public naomijnguyen/homebrew-bootwitch tap, using a checksum verified against the public v0.2.1 archive.
- Added auto-maintenance logging workflow via  and .

- Final Homebrew `url`/`sha256`/`version` updates are expected to be completed by the release workflow against the published `v0.2.1` tag.
