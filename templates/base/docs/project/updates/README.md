# Project updates

This folder contains dated summaries of substantial work sessions and
milestones. Use `update-template.md` so each update is easy for a person or a
coding assistant to scan.

Recommended filename:

```text
YYYY-MM-DD-short-topic.md
```

Updates preserve history. The neighboring `state.md` should describe only the
current state.

Use both a conversation link and its task ID when available. Links can depend
on an application or account, while the ID remains a precise fallback. Record
the Git state before and after the session so the written update can be matched
to the exact code history.
